# Alessio Fumagalli - Academic Homepage

This repository contains a GitHub Pages website for the academic CV of Alessio Fumagalli, built with the Minimal Mistakes Jekyll theme.

## Run locally

1. Install Ruby and Bundler.
2. Install dependencies:
   ```bash
   bundle install
   ```
3. Start the site:
   ```bash
   bundle exec jekyll serve
   ```
4. Open http://127.0.0.1:4000.

## Publish on GitHub Pages

1. Create a new repository named `alessiofumagalli.github.io` under https://github.com/alessiofumagalli.
2. Push this folder to that repository.
3. GitHub Pages will publish automatically.

If you prefer a project page repository, change `url` and `baseurl` in `_config.yml`.
